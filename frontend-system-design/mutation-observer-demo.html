🔍 Mutation Observer API Demo

What is Mutation Observer?

The Mutation Observer API provides a way to watch for changes being made to the DOM tree. It can observe additions/removals of nodes, attribute changes, and text content modifications.

Why use it? Much more efficient than deprecated mutation events. Perfect for: detecting dynamic content changes, third-party script integration, form validation, debugging, and tracking user-generated content.

Key Features: childList (node additions/removals), attributes (attribute changes), characterData (text changes), subtree (observe descendants), and attributeFilter (specific attributes).

💻 Code Implementation

// Select the target node to observe
const targetContainer = document.getElementById('targetContainer');

// Create a Mutation Observer instance
const observer = new MutationObserver((mutations) => {
    // Callback fires when mutations are observed
    mutations.forEach(mutation => {
        switch (mutation.type) {
            case 'childList':
                // Child nodes were added or removed
                console.log('Added nodes:', mutation.addedNodes);
                console.log('Removed nodes:', mutation.removedNodes);
                break;
                
            case 'attributes':
                // An attribute was modified
                console.log('Attribute changed:', mutation.attributeName);
                console.log('Old value:', mutation.oldValue);
                break;
                
            case 'characterData':
                // Text content was modified
                console.log('Text changed from:', mutation.oldValue);
                console.log('To:', mutation.target.textContent);
                break;
        }
    });
});

// Configuration: what to observe
const config = {
    childList: true,              // Watch for child additions/removals
    attributes: true,            // Watch for attribute changes
    characterData: true,         // Watch for text content changes
    subtree: true,               // Observe all descendants
    attributeOldValue: true,     // Record old attribute values
    characterDataOldValue: true, // Record old text values
    attributeFilter: ['class', 'style', 'data-status'] // Only these attributes
};

// Start observing
observer.observe(targetContainer, config);

// Later: stop observing
observer.disconnect();

// Resume observing with same config
observer.observe(targetContainer, config);
