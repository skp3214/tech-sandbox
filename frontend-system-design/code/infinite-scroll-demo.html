🚀 Infinite Scroll Demo

How It Works

This demo uses the Intersection Observer API to implement infinite scrolling efficiently. Instead of listening to scroll events (which fire hundreds of times), we observe a "sentinel" element at the bottom of the list. When it becomes visible, we automatically load more content.

Key Benefits: Better performance, cleaner code, and automatic handling of viewport changes.
