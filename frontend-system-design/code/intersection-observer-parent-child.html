🔍 Intersection Observer: Parent-Child Container Example

Understanding Intersection Observer with Parent Containers

Instead of observing elements relative to the viewport, you can observe elements relative to a parent container. This is useful for:

  • Lazy loading content inside scrollable divs/modals
  • Tracking visibility within carousels or sliders
  • Implementing infinite scroll in specific containers
  • Analytics tracking within specific sections

Key: Set root option to the parent element instead of null (viewport). The parent must be an ancestor of the observed elements and have overflow set.

💻 Code Implementation

// 1. Get the parent container element
const parentContainer = document.getElementById('scrollableParent');

// 2. Create Intersection Observer with parent as root
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            // Element entered parent's visible area
            entry.target.classList.add('visible');
            console.log('Element visible in parent:', entry.target);
        } else {
            // Element exited parent's visible area
            entry.target.classList.remove('visible');
            console.log('Element hidden from parent:', entry.target);
        }
    });
}, {
    // ⭐ KEY: Set root to parent container (not null/viewport)
    root: parentContainer,
    
    // Optional: Margin around parent's intersection area
    rootMargin: '0px',
    
    // Optional: Trigger when 10% of element is visible
    threshold: 0.1
});

// 3. Observe all child elements
const childElements = document.querySelectorAll('.child-item');
childElements.forEach(child => {
    observer.observe(child);
});

// 4. Don't forget to clean up!
window.addEventListener('beforeunload', () => {
    observer.disconnect();
});
